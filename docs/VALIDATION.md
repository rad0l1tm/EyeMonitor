# Проверка версии 0.1.0

Дата: 1 ноября 2026. Среда проверки: Linux x86_64, Python 3.12.14, без камеры и графической Wayland/X11-сессии. Qt запускался через `QT_QPA_PLATFORM=offscreen`.

## Выполнено

- Установка `pip install -e .` в новое виртуальное окружение — успешно. Основные разрешённые версии: NumPy 1.26.4, MediaPipe 0.10.21, PySide6 6.8.3, OpenCV contrib 4.11.0.86. Полный набор для Python 3.12 — `requirements-linux-py312.lock`.
- `python -m pip check` — No broken requirements found.
- `python -m unittest discover -s tests -v` — **18 тестов, все прошли**.
- 14 тестов численного ядра: перенос координат радужки, устойчивость локальных осей глаз к повороту кадра, закрытие глаз, отсутствие радужек, регрессия на новых синтетических целях, отбрасывание выхода за диапазон, некорректные данные, профили и контекст экрана/камеры, крайние области сетки, dwell, сброс при потере сигнала, атомарное обновление JSON.
- 4 интеграционных теста Qt с подставленной камерой: полный цикл 9 целей + 5 независимых целей проверки; запись профиля и JSON; сброс координат при потере сигнала; отказ от устаревшего результата; ожидание при отсутствии глаз; остановка с `valid=false`.
- Проверены `--list-screens`, отрисовка и компоновка главного окна, компиляция Python и синтаксис shell-скриптов.
- Официальный Face Landmarker v1 скачан отдельной командой. Полученный SHA256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`. Это отпечаток проверенного в этой среде файла, не независимое подтверждение его подлинности.
- Модель создана с `BaseOptions.Delegate.CPU` и обработала пустой RGB-кадр 640×480. Результат — отсутствие лица, без аварии. Повторный прогон 30 пустых кадров занял 0.120 с, peak RSS процесса с моделью — 186.6 MiB. **Это только smoke test без лица, камеры и UI: эти цифры не характеризуют полный трекинг пользователя.**
- MediaPipe выводил диагностику недоступного EGL/GPU, cpuinfo и отключения feedback tensors. CPU inference при этом завершился успешно.

## Повторение

Из каталога проекта после установки зависимостей и модели:

```bash
.venv/bin/python -m pip check
.venv/bin/python -m unittest discover -s tests -v
QT_QPA_PLATFORM=offscreen .venv/bin/eyemonitor --list-screens
.venv/bin/python scripts/smoke_model.py
```

Чтобы повторить разрешение зависимостей именно проверенной конфигурации Python 3.12:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-linux-py312.lock
.venv/bin/python -m pip install --no-deps -e .
```

Файл lock относится только к Linux x86_64/Python 3.12. Для Python 3.10–3.11 обычная установка по `pyproject.toml` подбирает совместимые транзитивные версии и требует отдельной проверки.

## Что ещё проверить на целевом ПК

1. Открытие реальной V4L2-камеры, размер кадров, права и отключение USB во время работы.
2. Полноэкранные цели именно на выбранном мониторе в Hyprland; аналогично в GNOME, Plasma, Sway и X11 WM. Отдельно проверить дробный масштаб и отключение монитора.
3. Калибровку реального пользователя и попадания на пяти целях. Повторить несколько раз с разным освещением и очками; не смешивать обучающие и проверочные цели.
4. RSS, загрузку CPU, задержку и стабильность при 10/15 FPS во время 30-минутного использования с лицом в кадре. RSS должен стабилизироваться; проверка пустого кадра этого не доказывает.
5. Сброс JSON при закрытии глаз, выходе из кадра, паузе и закрытии приложения. Потребитель должен отдельно отвергать устаревший файл после `kill -9`.

Матрица дистрибутивов и WM в README описывает предусмотренные пути установки и архитектурную переносимость. Испытания на всех перечисленных ОС и оценка точности по реальной веб-камере в этой среде не выполнялись.
